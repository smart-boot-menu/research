# sbm-lab boot measurements, 2026-11-26

These numbers come from `sbm-lab` runs on the development Mac. They are not physical-hardware measurements. QEMU `virt` is not an Apple Silicon Mac.

## Host

- QEMU emulator version 11.1.3 at `/opt/homebrew/bin`.
- `qemu-system-aarch64 -accel help` lists `hvf` and `tcg`. `kern.hv_support` is 1.
- `qemu-system-x86_64 -accel help` lists only `tcg`.
- swtpm TPM emulator version 0.10.2.
- Firmware banner observed on both guests: `edk2-stable202408-prebuilt.qemu.org` (Homebrew EDK2, built 16:28:50 on Sep 12 2024). ADR-008 names `edk2-stable202611`. That banner was not observed.
- x86 OVMF code is 3,653,632 bytes and the variable template is 540,672 bytes. They boot as a split pflash pair.
- Headless screenshots are QMP `screendump` PPM files. This QEMU build has no VNC backend.
